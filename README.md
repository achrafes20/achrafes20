## 🚀 Projets phares

### 🥗 Nutrition Risk Classifier — ML End-to-End
> **Python · XGBoost · scikit-learn · FastAPI · Streamlit · Docker**

Pipeline ML complet de bout en bout sur +10 000 produits alimentaires (API Open Food Facts).

- 📊 Classification supervisée Nutri-Score E — Recall **0.94** · F1-macro **0.94** · ROC-AUC **0.99**
- 🔬 EDA, feature engineering, modélisation XGBoost avec tuning `RandomizedSearchCV`
- 🚀 Déploiement : API REST **FastAPI** + interface **Streamlit** + conteneurisation **Docker Hub**

---

Application de gestion complète (membres, abonnements, coachs, paiements, équipements).

- ⚙️ Backend Laravel 10 : CRUD, authentification, dashboard, API REST
- 🖥️ Frontend Angular 16 : site vitrine responsive
- 🐳 Infrastructure Docker Compose : PHP-FPM, Nginx, MySQL, phpMyAdmin
